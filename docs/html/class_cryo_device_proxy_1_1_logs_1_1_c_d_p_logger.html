Initiates a logging instance. This function must be called before any logging can be performed. It sets up the log output. Supported values are "console" or "file". Default is "console". It sets up the log level. Supported values are Fatal, Error, Warning, Information, Debug, Verbose The Logger will rotate log files based on the maximum size specified. So, the oldest file will be deleted after creating a new backup of the current log file. A backup of current log file is created when the maximum file size (in MB) is reached. This function also allows initialization of the actual log name. If log file name is "app_log.txt", then the backup files are named as app_log.0.txt, app_log.1.txt...

Parameters
log_toDestination for logged data.
log_levelThe log level controlling the amount of logged data.
max_file_countIf logging to file, the maximum number of backup logs maintained.
max_file_size_mbThe maximum size in megabytes of each log file.
log_file_nameThe name of the log file to use to store logging data.

◆ IsEnabled()

static bool CryoDeviceProxy.Logs.CDPLogger.IsEnabled ( LogEventLevel  curr_level)
staticprivate

This function controls the actual data that gets written based on the setup log level. If the log level is set to "Information", any data written to function Verbose will not be logged to destination. Thus the log output could be varied without recompiling the application. This is called by each of the log functions before writing data to the destination. If the function log level is greater than the set level, then the function returns enabled as true, or false otherwise.
