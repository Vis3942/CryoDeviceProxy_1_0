static async Task< string[]> CryoDeviceProxy.BLL.DeviceBLL.PingDataAsync ( PingPacket  pp_recv,
string  context_str 
)
staticprivate

This function implements an asynchronous call to the backend server with device ping data, and returns the response received in a string array, or a null string array if error or exception. If the device was found in the backend server, the response array returned from this function contains

  • Index 0: service_tag
  • Index 1: respone string

Response string obtained from server is a semicolon separated values, "x0;x1;x2;x3;x4;x5;x6;x7" where x's can take values "1" or "0". The interpretation for the device is:

  • x0: "0" => ack for ping data, "1" => retransmit ping packet
  • x1: "0" => no firmware available, "1" => firmware for device is available
  • x2: "0" => no language pack available, "1" => language pack for device is available
  • x3: "0" => not approved for pay-per-use, "1" => approved as a pay-per-use device
  • x4: "0" => unit is free device, "1" => unit is a pay-per-use device
  • x5: "0" => allowed all operations, "1" => unit is decommissioned
  • x6: "0" => no user interface connection request, "1" => user interface connection pending
  • x7: reserved, default is always "0"
Parameters
pp_recvThe PingPacket object containing the information about the ping data received from the device.
context_strThe context string that contains the calling task information for metrics and tracing.
Returns
String array based on the response of the server or error or exception
